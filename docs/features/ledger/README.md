## Timing in one paragraph

In legacy, a build's identity is perks (1 point each, from level 1) and tier-1 skills. Its capstones need 28–30 points in one path, which makes them mid-to-late game and forces specialisation. In 5.x's new tree, perks have 3 levels and are chained (3 points to max, 1–3 points to unlock), while every capstone-like effect sits 4–7 points from a root. Perks get dearer and capstones much cheaper, and the 12 skill slots become the new tree's main limit.
