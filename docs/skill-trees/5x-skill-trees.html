5.x skill trees (vanilla)

Vanilla game 5.x. Every skill and perk at its maximum level, with the tooltip text and numbers the game would show at that level (computed from the tooltip code and the skill XML; values that scale with Geralt's stats are given for base stats, hover ⓘ or show the notes). Generated 2026-10-05 for the SKL decisions; not authoritative, check the entry in docs/features/skl.md. 5.x has two trees: the classic one (behind the hidden UseLegacySkillTree setting) and the new one (default). Skills marked both trees are shared: the same skill, with the same effect, in both.
