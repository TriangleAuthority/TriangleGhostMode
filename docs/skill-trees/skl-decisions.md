# SKL decisions: legacy and 5.x side by side

Two parts. **Decisions:** each SKL question with the skills it is about (legacy Ghost Mode's text at max level, 5.x's at max level), the question and the recommendation. This file is where SKL's decisions are kept and revisited; the feature entries in [skl.md](../features/skl.md) refer to them by number. **Every skill:** one row per skill in both games, including 5.x's new-tree skills with no legacy counterpart. Skill texts are the in-game tooltips computed for the max level (base stats where a value scales with Geralt's stats; 5.x's tooltips include the path passive line, which the port removes); text in *italics* describes behaviour that no tooltip states. Full trees: [legacy-skill-tree.html](legacy-skill-tree.html), [5x-skill-trees.html](5x-skill-trees.html). Rules: [balance.md](../features/balance.md). Generated 2026-10-05 from the code; unverified.

# Decisions

Revised 2026-10-05 under [balance.md](../features/balance.md): the trees are separated, the classic tree is legacy Ghost Mode's (legacy's values, levels and tier points; the default), and the new tree is the experimental one. For the classic tree, almost every question is settled as legacy (marked **Decided**). New-tree questions are decided in phase 2 against the [ledger](../features/ledger/README.md), the archetypes and the rules B1–B10 (B5: a mechanism is judged by its effective power, including how easily it triggers). Batch E lists the new tree's gaps that no single skill covers. This list is revisited often. **SKL is paused until DMG is ported (2026-10-06); see [where it stopped](../features/skl.md#area-decisions).**
