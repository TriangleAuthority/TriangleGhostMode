# SKL decisions: legacy and 5.x side by side

Two parts. **Decisions:** each SKL question with the skills it is about (legacy Ghost Mode's text at max level, 5.x's at max level), the question and the recommendation. This file is where SKL's decisions are kept and revisited; the feature entries in [skl.md](../features/skl.md) refer to them by number. **Every skill:** one row per skill in both games, including 5.x's new-tree skills with no legacy counterpart. Skill texts are the in-game tooltips computed for the max level (base stats where a value scales with Geralt's stats; 5.x's tooltips include the path passive line, which the port removes); text in *italics* describes behaviour that no tooltip states. Full trees: [legacy-skill-tree.html](legacy-skill-tree.html), [5x-skill-trees.html](5x-skill-trees.html). Rules: [balance.md](../features/balance.md). The skill texts were generated from the code (unverified in game).

# Decisions

The per-skill pass is complete (project owner, 2026-10-06 to 2026-10-11), under [balance.md](../features/balance.md): the trees are separated; the classic tree is legacy Ghost Mode's (legacy's values, levels and tier points; the default); the new tree carries legacy's skills on 3 levels, gated by legacy's tiers scaled ×3/5 (D59) and under legacy's names, with a few new designs by the project owner (Muscle Memory D1 and D53, Strength Training D54, Crushing Blows D55, Precise Blows D57, Cold Blood D13, Wolf School and Viper School D61), which are new design, not deviations from legacy. Every question below is **Decided**; D45 (one SKL-19 pass) and D59's revisit (moved to XP) were porter's calls, confirmed by the owner (2026-10-16). Batch E lists the gaps 5.x's new tree had and what closed them. D7, D8, D19, D35 and D36 are not used. Where the area stands: [skl.md](../features/skl.md#area-decisions).
