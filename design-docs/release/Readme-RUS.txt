Ghost Mode v4.0 by wghost81 aka Wasteland Ghost
===============================================

Начиная с версии 4.0 GM требует наличия Community Patch - Base и Shared Imports!
Все мои моды, совместимые с Unification Patch, также совместимы и с Community Patch,
поэтому обновляйтесь смело.

При обновлении с предыдущих версий мода, удалите старую версию полностью и установите
новую. Используйте консольную команду cleardevelop для сброса персонажа и перестройки
деревьев развития. При использовании команды вы ничего не теряете, просто потом надо
будет заново распределить очки умений.

Установка
=========

Для работы мода требуются Community Patch - Base и Shared Imports.

Для автоматической установки мода вместе с меню рекомендуется использовать The Witcher 3
Mod Manager. Инструкции для ручной установки находятся чуть ниже. Имейте ввиду, что
менеджер модов не устраняет конфликты, для этого по-прежнему нужен Script Merger!

При наличии других модов конфликты находятся и устраняются с помощью Script Merger.

Совместимость с отдельными модами:
* Preparations - файл effects_ep2.xml объединять в Script Merger не надо, но надо убедиться,
  что Ghost Mode имеет приоритет (по умолчанию так и будет, т.к. modGhostMode загружается
  перед modPreparations).
* Nitpicker's Patch - bundled-файлы объединять не надо, но надо убедиться, что Ghost Mode
  имеет приоритет (идет первым в списке конфликтов). Приоритет легко поменять, переименовав
  папку modNitpicker в modZNitpicker.
* Besserwisser's Patch - не объединяйте ничего (включая скрипты!), но убедитесь, что Ghost
  Mode имеет приоритет (идет первым в списке конфликтов).
* All NPC Scabbards - bundled-файлы объединять не надо, но надо убедиться, что Ghost Mode
  имеет приоритет (идет первым в списке конфликтов). Приоритет относительно Nitpicker's Patch
  не имеет значения, т.к. Ghost Mode перекрывает оба этих мода. Приоритет легко поменять,
  переименовав папку modScabbards в modZScabbards.
* Better Icons mod - не используйте версию мода, которая меняет xml, ищите на Нексусе русскую
  версию, которая меняет непосредственно иконки.

Общий совет по объединению: GM всегда должен иметь наивысший приоритет (ws, w3ent, xml, etc.)!
Если вы даёте приоритет другому моду (и этот мод не был сделан специально для текущей версии
GM), игра может и запустится и может даже казаться нормально работающей, но позже вы можете
обнаружить неприятные баги: неправильные уровни противников, неправильный лут, неправильные
способности. Убить финального босса одним ударом не очень весело, но вполне возможно, если
проигнорировать приоритет ради "всего лишь" косметического мода.

ВАЖНО: перевойдите в игру после завершения компиляции - если этого не сделать, можно встретить
различные неприятные баги, например, неверное (-1) количество зелий в инвентаре, возможно,
что-то ещё.

Рекомендованные настройки мода: используйте пресеты "по умолчанию" и "рекомендовано" в
настройках мода.

Установка вручную
=================

Для установки моды распакуйте modGhostMode и modGMTutorials в папку
[Путь к The Witcher 3]\Mods. Используйте Script Merger для разрешения конфликтов с другими
модами.

Для того, чтобы заработало внутриигровое меню, надо скопировать папку
[Путь к The Witcher 3]\Mods\modGhostMode\bin в папку [Путь к The Witcher 3].

Удаление вручную
================

Удалите папки modGhostMode и modGMTutorials из папки [Путь к The Witcher 3]\Mods.
Запустите Script Merger для обновления объединённых скриптов.

Удалите [Путь к The Witcher 3]\bin\config\r4game\user_config_matrix\pc\modSignsConfig.xml.
